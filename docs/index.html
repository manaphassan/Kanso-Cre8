MULTI-PLATFORM DESKTOP

Native Fedora Linux Setup.

SS-CAM runs natively on Fedora Linux (Wayland / X11) powered by Avalonia UI & .NET 8.

Option A: Fedora Terminal Launch

Run directly from repository via .NET 8 CLI

bash — fedora@workstation 
# 1. Clone SS-CAM repository
git clone https://github.com/SuamiSihat/ss_cam.git
# 2. Launch native Linux desktop app
dotnet run --project src/SS-CAM.Linux/SS-CAM.Linux.csproj

Option B: Fedora RPM Package

Install standalone RPM package for GNOME / Wayland

sudo dnf install 
# Install native RPM package on Fedora Workstation
sudo dnf install ./SS-CAM.Linux-v3.5.0-x86_64.rpm

# Synology Drive Client target auto-links to:
~/SynologyDrive/
