Privacy Policy for SS-CAM

Effective Date: September 1, 2026

SuamiSihat Creative Production ("we", "our", or "us") operates the SS-CAM (SuamiSihat Creative Assets Management) desktop, web, and mobile companion applications.

1. Information We Collect

SS-CAM is an enterprise creative assets management tool for designers, copywriters, and production personnel. The app collects minimal information strictly necessary for studio operation:

  • Account Identification: Staff username and profile names used to authenticate against the private studio server.
  • Creative Assets & Project Data: Project briefs, copy scripts, quick notes, and review annotations created by users.
  • Device & Network State: Basic network connectivity status to enable seamless offline caching and automatic sync queueing.

2. How Data is Handled and Stored

All project data and metadata are transmitted securely via encrypted HTTPS / TLS connections directly to your private studio server (Synology NAS). We do not sell, rent, or transfer user data to third-party data brokers, advertising networks, or analytics tracking services.

3. Third-Party Services & Permissions

SS-CAM requests only essential permissions:

  • INTERNET: Connect to the studio NAS server for real-time task synchronization.
  • ACCESS_NETWORK_STATE: Detect offline mode to cache user edits locally.
  • POST_NOTIFICATIONS: Deliver studio alerts, deliverable reviews, and prayer times notifications.

No high-risk permissions (such as GPS location, camera, microphone, or external storage scanning) are requested or used.

4. Data Retention & Deletion

Project assets and user profiles are retained within the organization's private workspace. Users may delete their local application cache at any time via the Android Settings app or request account removal through the studio system administrator.
